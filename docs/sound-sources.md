# Sound sources for letter names (status: NOT CHOSEN YET)

Rule: use only sounds with a clear licence. Prefer CC0 (public domain).
Avoid CC BY-SA for this app (share-alike terms would apply to the app's audio).
CC BY works only if the credit is shown in the app (Settings > Credits).

## Options

1. **Owner records** the letters with a native Arabic speaker and an English speaker (best quality, no licence risk).
2. **Generate with the voice tool** (add_voice / generate_speech): consistent, quick. Check every letter with a native speaker.
3. **Freesound.org with the CC0 filter**: search each letter. Record the file ID and licence for each.

Credits file to create when sounds are chosen: `docs/credits.md`.
